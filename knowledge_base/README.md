# Knowledge Base Directory

This directory stores role-specific technical reference documents used by the RAG (Retrieval-Augmented Generation) pipeline.

## Structure

- `backend_engineer/`: System design, database optimization, caching strategies, REST/gRPC API architecture, and microservices concepts.
- `ai_ml_engineer/`: Machine learning principles, neural network architectures, model evaluation metrics, deep learning optimization, and LLM fine-tuning/RAG context limits.
- `data_science/`: Statistical inference, exploratory data analysis, feature engineering strategies, hypothesis testing, and model validation techniques.

## Note on Demonstration Corpus vs. Full Books

The documents in this repository serve as a lightweight, clean demonstration knowledge base for development and evaluation. Full textbook sources or external reference manuals can be dropped directly into the respective role folders (`.txt` or `.md` format) to automatically expand vector search capabilities during ingestion.
